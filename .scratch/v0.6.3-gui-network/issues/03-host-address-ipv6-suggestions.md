# 03: Host 字段改为枚举地址 combobox 并补齐 IPv6

**What to build:** Network configuration 的 Host 字段改为 combobox：主控件只列枚举的本机地址（IPv4 在前、可用 IPv6 在后），末尾提供显式的“自定义…”入口；不在主控件接受任意自由输入。IPv6 候选排除 link-local 与 Teredo。

## Agent Brief

**Category:** bug
**Summary:** Windows 实测下拉只有 IPv4；datalist 会按当前值过滤候选，且维护者要求主控件不再接受任意填入。

**Current behavior:**
- 后端 `local_host_addresses()` 枚举非 loopback IPv4 与可用 IPv6，Bootstrap 以 `hostAddresses` 传给前端。
- Host 字段仍是 `<input type="text" list="host-addresses">` + `<datalist>`。
- Windows 真机（CI exe，SHA-256 已确认为 `095f2d65…`）上，机器存在全局 IPv6（以太网 `2409:…`）、Tailscale ULA（`fd7a:…`）和 Teredo（`2001:0:…`），但下拉只显示 IPv4。
- 最可能原因：Chromium/WebView2 的 datalist 按输入框当前值过滤选项；字段里的 IPv4 把 IPv6 选项藏掉。
- 维护者决定：主控件改为 combobox，只列枚举值 + 显式“自定义…”；IPv6 候选排除 Teredo（`2001:0::/32`），保留全局/ULA。

**Desired behavior:**
- 主控件是下拉选择，列出全部 `hostAddresses`，**不受当前值过滤**；默认地址（IPv4）在前，IPv6 在后。
- 末尾有“自定义…”选项；选中后展开文本框，允许输入主机名或 IP（不含 `%scope`）。
- 自定义输入在保存时规范化（`trim`、去掉成对包围 IPv6 的方括号）并校验；空值、非法主机名、带 `%scope` 的值给出本地化错误并回滚到上次保存值。
- 保存失败后，界面显示的值必须与后端已保存值一致；启动 Server 不得使用界面之外的值。
- IPv6 候选排除 `::1`、未指定、multicast、link-local、Teredo（`2001:0::/32`）。
- 启动时在 `server.log` 写一行 `host suggestions: [...]`（`logging::info`），便于 Windows 上区分“后端未枚举”与“前端未显示”。

**Key interfaces:**
- `local_host_addresses()` / `is_usable_ipv6()`：加入 Teredo 排除。
- Bootstrap 的 `hostAddresses`：格式不变；新增启动日志。
- `ServerView.svelte` 的 Host 控件：select + 自定义输入。
- `store.svelte.ts` 的 `persist()`：本地校验失败时回滚到上次保存值；保存成功才更新状态。
- `Settings::validate` / `save_settings`：主机规范化与格式校验（允许 IP 字面量与合法主机名；拒绝空值与 `%scope`）。

**Acceptance criteria:**
- [ ] 380×560 下 Host 主控件是下拉，打开后显示全部枚举地址，与当前值无关。
- [ ] 枚举包含全局/ULA IPv6；不含 link-local、`::1`、未指定、multicast、Teredo。
- [ ] 选择枚举地址后立即保存并回显；重启后保留。
- [ ] “自定义…”可输入主机名或 IP；保存时去掉 IPv6 方括号并规范化。
- [ ] 空值、非法主机名、`%scope` 被拒绝，显示本地化错误，并回滚到上次保存值。
- [ ] 保存失败后启动不会使用旧的后端值；界面与 `config.ini` 一致。
- [ ] `server.log` 在启动时包含 `host suggestions: [...]`。
- [ ] Rust 单测覆盖 Teredo/link-local/全局/ULA 过滤；`cargo test`、`svelte-check`、生产构建通过。
- [ ] Windows 真机复验下拉与自定义路径；记录 `PASS` / `FAIL`。

**Out of scope:**
- 改变 v2 绑定地址或二维码广告地址（见 #04）。
- 在候选中显示网卡名称、接口状态或网络变化轮询。
- 允许主控件自由输入；自定义必须通过明确入口。
