# 03: Host 地址建议枚举 IPv6 接口地址

> *This was generated by AI during triage.*

**What to build:** Network configuration 的 Host 建议列表在现有 IPv4 之外，补充本机可用的非 loopback IPv6 接口地址，同时保留手动输入。

**Blocked by:** 无

**Category:** enhancement
**Status:** ready-for-agent

## Agent Brief

**Category:** enhancement
**Summary:** Host 下拉只枚举 IPv4；使用 IPv6 的用户没有任何候选，只能手填。

**Current behavior:**
- 后端枚举本机非 loopback IPv4 地址，去重后把 v0.3.4 的默认地址放最前，作为 `hostAddresses` 传给前端。
- Host 输入框是可编辑文本框 + `<datalist>`；候选里只有 IPv4，IPv6 地址永远不会出现。
- 维护者在 Windows 上确认：下拉有 IPv4 候选，缺少 IPv6。

**Desired behavior:**
- 建议列表同时包含可用的非 loopback IPv6 地址（全局单播与 ULA），去重后排在 IPv4 之后。
- 排除 `::1`、未指定地址，以及带 `%scope` 的 link-local 地址；后者无法写入配对 payload（校验禁止 `%`），不应作为候选。
- IPv4 的顺序与“默认地址在前”的行为保持不变；`default_host()` 的结果不变。
- Host 字段仍可自由输入；选择建议后正常持久化。

**Key interfaces:**
- 现有的本机地址枚举函数（当前返回 `Vec<Ipv4Addr>`）与 `default_host()`。
- 可新增一个返回 `IpAddr` 或已格式化字符串的枚举函数；`hostAddresses` 仍是字符串数组。
- Bootstrap 的 `hostAddresses` 字段格式不变，前端 datalist 无需改结构。
- v1 绑定、v2 启动与 Wire Protocol 行为不变。

**Acceptance criteria:**
- [ ] `hostAddresses` 包含非 loopback 的 IPv6 地址（全局/ULA），去重，且不含 `::1`、未指定地址、带 `%scope` 的地址。
- [ ] IPv4 候选及其“默认地址在前”的顺序不变。
- [ ] `default_host()` 仍返回原来的 IPv4 默认值；v1 绑定不受影响。
- [ ] 单元测试覆盖：仅 IPv4、双栈、仅 loopback、重复地址、link-local 排除。
- [ ] Host 仍可自由输入；选择 IPv6 建议后能保存并回显。
- [ ] `cargo test`、`svelte-check`、生产构建通过。
- [ ] 在 Windows 真机复验下拉候选；无法复验时记 `NOT RUN`。

**Out of scope:**
- 改变 v2 绑定地址或二维码广告地址（见 #04）。
- 在候选中显示网卡名称、接口状态或网络变化轮询。
- 把 datalist 改成 select；保留手动输入是硬要求。

## Comments

- 2026-11-23: triage 由维护者在 v0.6.2 真机测试中报告。维护者确认现象为“只有 IPv4 候选，没有 IPv6”，因此归类为 enhancement。核实：v0.6.2 的枚举路径只接受 `IfAddr::V4` 且过滤 loopback；v0.3.4 对等实现也只覆盖 IPv4。
