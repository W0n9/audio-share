# v0.6.3 GUI 与网络配置修复

> *This was generated by AI during triage.*

**Status:** resolved

## 目标

修复 v0.6.2 真机测试发现的配对对话框与网络配置问题，并让 IPv6 Host 在建议列表和二维码广告地址里真正可用。

## 范围

- **#01 配对对话框**：出现待批准请求时，接受/拒绝按钮无需滚动即可见。
- **#02 确认框**：撤销/删除改用应用内模态框，替换原生 `window.confirm`。
- **#03 Host 控件**：改为 combobox（枚举地址 + 显式“自定义…”）；IPv6 排除 link-local 与 Teredo，保留全局/ULA。
- **#04 二维码地址**：`addr` 使用配置的 Host；IPv6 编码为 `[addr]:port`；v2 绑定保持双栈；Host 保存时规范化/校验。
- **#06 Android v2 图标**：Manifest 声明启动器图标，复用 Tauri / v1 Client 同一套图标资源，消除系统默认图标。

## 决策

- Host 设置**只影响二维码广告地址**，不改变 v2 的 `::` 双栈绑定（2026-11-23 维护者裁决）。
- Host 主控件是 **combobox**：主控件只列枚举值，末尾“自定义…”允许输入主机名或 IP；**主控件不接受任意自由输入**（2026-11-24 维护者裁决）。
- IPv6 候选排除 link-local、loopback、未指定、multicast 与 **Teredo（`2001:0::/32`）**；保留全局单播与 ULA（2026-11-24 维护者裁决）。
- 带 `%scope` 的地址不进入候选；GUI 保存时明确拒绝并给出本地化错误，配置/CLI 路径仍回落到默认地址。
- GUI **不允许保存空 Host**；“Host 为空回落”只适用于手改配置、`as-cmd` 与 QR 地址提示。
- 保存失败必须回滚到上次保存值；启动 Server 不得使用界面之外的值。
- #01/#02 独立；#03/#04 共享 Host 保存、规范化与状态回滚路径，由同一 implementer 处理。
