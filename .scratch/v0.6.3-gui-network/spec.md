# v0.6.3 GUI 与网络配置修复

> *This was generated by AI during triage.*

**Status:** ready-for-agent

## 目标

修复 v0.6.2 真机测试发现的配对对话框与网络配置问题，并让 IPv6 Host 在建议列表和二维码广告地址里真正可用。

## 范围

- **#01 配对对话框**：出现待批准请求时，接受/拒绝按钮无需滚动即可见。
- **#02 确认框**：撤销/删除改用应用内模态框，替换原生 `window.confirm`。
- **#03 Host 建议**：在 IPv4 之外枚举非 loopback IPv6 接口地址。
- **#04 二维码地址**：`addr` 使用配置的 Host；IPv6 编码为 `[addr]:port`；v2 绑定保持双栈。

## 决策

- Host 设置**只影响二维码广告地址**，不改变 v2 的 `::` 双栈绑定（2026-11-23 维护者裁决）。
- 带 `%scope` 的 link-local 地址不进入候选，也不直接写入配对 payload。
- 四个 ticket 彼此独立，可并行；#03 与 #04 可以共享地址枚举/格式化辅助函数。

## 非目标

- 多 Client 并发支持，以及 README / 发布说明中“One v2 Client per Server”承诺的调整。
- 让 Host 同时控制 v2 的绑定地址。
- 全局 GUI 重构或设计系统改造。

## 证据边界

- 自动化测试通过后仍需 Windows 真机视觉复验；无法复验时记 `NOT RUN`，不得以代码推断冒充 `PASS`。
- 双设备同时播放的实测结果另按 `docs/agents/evidence-policy.md` 记录，不并入本 spec 的验收。
