# Audio Share 0.6.0

This release brings bounded jitter buffering, loss concealment, and playback
clock-drift correction to single-client PCM streaming over the encrypted,
paired Wire Protocol v2. The Windows and Linux Server packages include the GUI
and/or `as-cmd`; the v2 Android Client ships as **two separately signed APKs**,
one for `arm64-v8a` (phones) and one for `x86_64` (emulators and x86 devices).
Download the one that matches your device.

## Downloads

Each asset has a `.sha256` sidecar in `sha256sum` format. Verify a download
before opening it:

```sh
sha256sum -c audio-share-client-v2-0.6.0-arm64-v8a.apk.sha256
```

| Platform | Asset |
|---|---|
| Android (arm64 phones) | `audio-share-client-v2-0.6.0-arm64-v8a.apk` |
| Android (x86_64) | `audio-share-client-v2-0.6.0-x86_64.apk` |
| Windows GUI | `AudioShareServer.exe` |
| Windows headless | `audio-share-server-cmd-windows.zip` |
| Linux GUI (deb) | `AudioShareServer_0.6.0_amd64.deb` |
| Linux GUI (AppImage) | `AudioShareServer_0.6.0_amd64.AppImage` |
| Linux headless | `audio-share-server-cmd-linux.tar.gz` |

The v2 Server listens on UDP port 65531 (QUIC); allow it through the firewall.
Windows GUI requires the WebView2 Runtime; Linux GUI requires WebKitGTK 4.1,
GTK 3, the StatusNotifier appindicator, and a running PipeWire session with a
session manager. See the [README](../../README.md) for pairing, `as-cmd` flags,
and build instructions.

## Compatibility and upgrade

- One v2 Client per Server is supported; concurrent phones and multi-client
  isolation are outside this release.
- The v2 APK (`dev.audioshare.v2`) installs alongside the existing v1 Android
  app. The v1 APK and its F-Droid listing are not replaced. **Use v1 only on a
  trusted network:** it is unencrypted and unauthenticated. A failed v2
  connection never automatically falls back to v1 or plaintext.
- If an older v2 beta leaves stale credentials (error 205), uninstall the old
  v2 app, install the new APK, and pair again. Uninstalling removes the app's
  saved pairings.
- Verify downloads against their accompanying SHA-256 checksums.

## Validation limits

Installation and playback of the release APKs were verified on real Android
hardware, and the release Server packages were run and verified on Windows.
The upgrade path from older v2 beta builds is waived: uninstall the old v2 app
before installing this release (see "Compatibility and upgrade" above).

The acoustic latency baseline and the 60-minute single-client run were waived;
this release does **not** claim the p95/p99 audible-latency targets.
Real-network impairment testing, device clock-drift injection, and listening
A/B for the drift-control change were not run. The impairment matrix was
exercised on host only. Multi-client and full migration/rollback acceptance are
outside this release.
