# Audio Share 0.6.0

This release brings bounded jitter buffering, loss concealment, and playback clock-drift correction to single-client PCM streaming over the encrypted, paired Wire Protocol v2. The Windows and Linux Server packages include the GUI and/or `as-cmd`; the v2 Android Client is distributed as a separately signed APK for arm64-v8a and x86_64.

## Compatibility and upgrade

- One v2 Client per Server is supported; concurrent phones and multi-client isolation are outside this release.
- The v2 APK (`dev.audioshare.v2`) installs alongside the existing v1 Android app. The v1 APK and its F-Droid listing are not replaced. **Use v1 only on a trusted network:** it is unencrypted and unauthenticated. A failed v2 connection never automatically falls back to v1 or plaintext.
- If an older v2 beta leaves stale credentials (error 205), uninstall the old v2 app, install the new APK, and pair again. Uninstalling removes the app's saved pairings.
- Verify downloads against their accompanying SHA-256 checksums.

## Validation limits

Windows and Android hardware testing on pre-release builds covered single-client playback and drift-control behavior. The acoustic latency baseline and the 60-minute single-client run were waived; this release does **not** claim the p95/p99 audible-latency targets. Real-network impairment testing, device clock-drift injection, and listening A/B for the drift-control change were not run. The impairment matrix was exercised on host only. Multi-client and full migration/rollback acceptance are outside this release.
